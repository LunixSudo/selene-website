Selene Launcher

Лаунчер Minecraft: Java Edition для лицензионных аккаунтов. Ставит моды и модпаки с Modrinth и CurseForge и хорошо работает на слабых ПК.

Скачать для Windows Исходный код

Первого релиза пока нет. Тестовые сборки лежат на GitHub.

Почему Selene

Вы играете со своей лицензией Minecraft: Java Edition и входите через аккаунт Microsoft. Пиратского режима нет.

Работает на том ПК, что у вас есть

Память, Java и её флаги подбираются под ваши ОЗУ, процессор и моды. Игра получает не больше половины памяти, 4 ГБ на ПК с 8 ГБ, и запускается на дискретной видеокарте. По умолчанию лаунчер закрывается, пока вы играете.

Загрузки идут, даже когда сайт лежит

Если не открываются Mojang, сайты загрузчиков, Modrinth или CurseForge, файлы берутся с их официальных зеркал, а потом с публичных. Каждый файл всё равно сверяется с официальной контрольной суммой.

Моды из обоих каталогов

Modrinth и CurseForge ищутся в одном поиске. Нужные зависимости ставятся сами, а обновление модпака не трогает моды, которые вы добавили сами.

Ваши данные не уходят с ПК

У лаунчера нет своих серверов, аналитики и рекламы. Вход хранится в системном хранилище учётных данных и отправляется только Microsoft и Mojang.

Что он умеет

Все версии игры от первых альф до свежих снапшотов, с Fabric, Quilt, Forge и NeoForge.

Игра

  • Нужная Java для каждой версии скачивается сама
  • Forge с 1.7.10 ставится в фоне, без окон
  • Новая сборка скачивается сразу, поэтому первый запуск быстрый

Моды и модпаки

  • Моды, ресурспаки, шейдеры и датапаки
  • Модпаки в той версии, которую вы выбрали
  • Импорт и экспорт .mrpack и .zip CurseForge
  • OptiFine с официального сайта прямо в лаунчере

Сборки

  • Группы, значки, обложки и ярлыки на рабочем столе
  • Перенос на другую версию игры с заменой модов на подходящие
  • Миры с резервными копиями, серверы в один клик, скриншоты

Аккаунты и скины

  • Несколько аккаунтов Microsoft сразу
  • Выбор и смена ника
  • 3D-просмотр скина, библиотека скинов и плащи

Если что-то сломалось

  • Консоль игры и разбор вылетов с советами
  • Кнопка, которая останавливает зависшую игру
  • «Сообщить о проблеме» само заполняет отчёт об ошибке

Языки

  • Русский и английский
  • Машинный перевод на украинский, немецкий, испанский, бразильский португальский, польский, турецкий и китайский

Просто по умолчанию, красиво по желанию

Стиль по умолчанию без размытия и бесконечных анимаций, поэтому он лёгкий для слабых ПК. В настройках можно включить стекло или Mica, живой фон, пиксельный шрифт в духе Minecraft и звук кликов, а потом сохранить всё это как свой набор.

Скачать

Официальные сборки есть только на этом сайте и на GitHub проекта. Копии с других сайтов не наши и могут быть изменены.

Windows

Windows 10 или 11, 64-бит. Установщик сам добавит Microsoft Edge WebView2, если его нет, а лаунчер обновляется сам. Портативная версия хранит все данные в своей папке.

Установщик Портативный .zip

Linux

64-бит, с WebKitGTK 4.1. Сборки для Linux новые и пока не обновляются сами.

AppImage .deb

Нужен аккаунт Microsoft с купленной Minecraft: Java Edition. Java лаунчер скачает сам. Установщик для Windows пока не подписан, поэтому SmartScreen может о нём предупредить.

Конфиденциальность

Лаунчер ничего не собирает. В политике конфиденциальности перечислен каждый сервис, к которому он обращается, что туда уходит и зачем.
