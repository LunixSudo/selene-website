# Security policy

This repository holds only the website. For a problem in Selene Launcher itself, see the
[launcher's security policy](https://github.com/LunixSudo/selene-launcher/security/policy).

To report a problem with the site, such as a download link that points somewhere it should
not, please do not open a public issue. Report it privately through
[GitHub security advisories](https://github.com/LunixSudo/selene-website/security/advisories/new).
You will get an answer within a week.
