Selene Launcher

A fast, good-looking launcher for Minecraft: Java Edition. Mods and modpacks in a click, careful with old PCs, and free of ads and tracking.

Download for Windows Source code

There is no release yet. Test builds are on GitHub.

Why Selene

You need a Minecraft: Java Edition license to play: you sign in with your Microsoft account. There is no cracked mode.

Light on old PCs

Memory, Java and its flags are picked for your RAM, processor and mods. The game starts on the discrete graphics card, and the launcher stays out of the way while you play.

Works when sites are down

If Mojang, a loader site, Modrinth or CurseForge cannot be reached, files come from official mirrors and then public ones, always checked against the official checksums.

Mods in a click

Modrinth and CurseForge in one catalog, dependencies added for you, and updates that keep the add-ons you put in yourself.

Private

No servers of its own, no analytics and no ads. Your sign-in stays in the system credential store and only goes to Microsoft and Mojang.

Everything in one place

From the first alphas to the newest snapshots, with Fabric, Quilt, Forge and NeoForge.

Game

  • Every version, with the right Java downloaded for each
  • Fabric, Quilt, Forge (from 1.7.10) and NeoForge, installed in the background
  • Automatic memory and Java arguments
  • A new instance downloads right away, so the first start is quick

Mods and modpacks

  • Mods, resource packs, shaders and data packs from Modrinth and CurseForge
  • Modpack updates that keep your own add-ons
  • Import and export of .mrpack and CurseForge .zip
  • OptiFine from its official site, right inside the launcher

Instances

  • Groups, icons, covers and desktop shortcuts
  • Moving to another game version with mods swapped for matching builds
  • Worlds with backups, servers in one click, screenshots
  • Play time for each instance and in total

Accounts and skins

  • Microsoft sign-in, several accounts at once
  • Picking and changing your player name in the launcher
  • An animated 3D skin preview, a skin library and capes

When something breaks

  • A game console and crash analysis with advice
  • A button that stops a hung game
  • "Report a problem" that fills in the bug report for you

Looks

  • Light and dark themes, Mica and glass styles
  • Optional live backgrounds, animations and click sounds
  • Russian and English, plus seven machine-translated languages
  • A Discord status that can be turned off

Download

Official builds come only from this site and the project's GitHub. Copies from other sites are not ours and may be changed.

Windows

Windows 10 or 11, 64-bit. The installer adds Microsoft Edge WebView2 if it is missing and updates itself. The portable version keeps all its data in its own folder.

Installer Portable .zip

Linux

64-bit, with WebKitGTK 4.1. The Linux builds are new and do not update themselves yet.

AppImage .deb

You need a Microsoft account that owns Minecraft: Java Edition. Java is downloaded by the launcher. The Windows installer is not signed yet, so SmartScreen may warn about it.

Your data stays yours

The launcher collects nothing and has no servers of its own. The privacy policy lists every service it talks to and why.
