Selene Launcher

A Minecraft: Java Edition launcher for licensed accounts. It installs mods and modpacks from Modrinth and CurseForge and runs well on old PCs.

Download for Windows Source code

The first release is not out yet. Test builds are on GitHub.

Why Selene

You play with your own Minecraft: Java Edition license and sign in with a Microsoft account. There is no cracked mode.

It runs on the PC you have

Memory, Java and its flags are picked for your RAM, processor and mods. The game gets at most half of the RAM, 4 GB on an 8 GB PC, and starts on the discrete graphics card. By default the launcher closes while you play.

Downloads work when a site is down

If Mojang, a loader site, Modrinth or CurseForge cannot be reached, files come from their official mirrors and then from public ones. Every file is still checked against the official checksum.

Mods from both catalogs

Modrinth and CurseForge share one search. Required dependencies are added for you, and a modpack update keeps the mods you put in yourself.

Nothing about you leaves your PC

The launcher has no servers of its own, no analytics and no ads. Your sign-in is kept in the system credential store and is sent only to Microsoft and Mojang.

What it can do

Every game version from the first alphas to the newest snapshots, with Fabric, Quilt, Forge and NeoForge.

Game

  • The right Java for each version, downloaded for you
  • Forge from 1.7.10, installed in the background without windows
  • A new instance downloads at once, so the first start is quick

Mods and modpacks

  • Mods, resource packs, shaders and data packs
  • Modpacks in the version you pick
  • Import and export of .mrpack and CurseForge .zip
  • OptiFine from its official site, opened inside the launcher

Instances

  • Groups, icons, covers and desktop shortcuts
  • Moving to another game version with mods swapped for matching builds
  • Worlds with backups, servers in one click, screenshots

Accounts and skins

  • Several Microsoft accounts at once
  • Picking and changing your player name
  • A 3D skin preview, a skin library and capes

When something breaks

  • A game console and crash analysis with advice
  • A button that stops a hung game
  • "Report a problem" fills in the bug report for you

Languages

  • Russian and English
  • Machine translations into Ukrainian, German, Spanish, Brazilian Portuguese, Polish, Turkish and Chinese

Plain by default, pretty when you want

The default style has no blur and no endless animations, so it stays light on old PCs. In the settings you can switch to glass or Mica, pick a live background, a pixel font in the style of Minecraft and click sounds, and save the look as a preset.

Download

Official builds come only from this site and the project's GitHub. Copies on other sites are not ours and may be changed.

Windows

Windows 10 or 11, 64-bit. The installer adds Microsoft Edge WebView2 if it is missing, and the launcher updates itself. The portable version keeps all its data in its own folder.

Installer Portable .zip

Linux

64-bit, with WebKitGTK 4.1. The Linux builds are new and do not update themselves yet.

AppImage .deb

You need a Microsoft account that owns Minecraft: Java Edition. The launcher downloads Java itself. The Windows installer is not signed yet, so SmartScreen may warn about it.

Privacy

The launcher collects nothing. The privacy policy lists every service it talks to, what it sends there and why.
