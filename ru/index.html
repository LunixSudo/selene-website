Selene Launcher

Быстрый и красивый лаунчер Minecraft: Java Edition. Моды и модпаки в один клик, бережёт слабые ПК, без рекламы и слежки.

Скачать для Windows Исходный код

Релиза пока нет. Тестовые сборки лежат на GitHub.

Почему Selene

Для игры нужна лицензия Minecraft: Java Edition: вы входите через аккаунт Microsoft. Пиратского режима нет.

Бережёт слабые ПК

Память, Java и её флаги подбираются под ваши ОЗУ, процессор и моды. Игра запускается на дискретной видеокарте, а лаунчер не мешает, пока вы играете.

Работает, когда сайты лежат

Если не открываются Mojang, сайты загрузчиков, Modrinth или CurseForge, файлы берутся с официальных зеркал, потом с публичных, и всегда сверяются с официальными контрольными суммами.

Моды в один клик

Modrinth и CurseForge в одном каталоге, зависимости ставятся сами, а обновления не трогают то, что вы добавили сами.

Приватно

Никаких своих серверов, аналитики и рекламы. Вход хранится в системном хранилище учётных данных и уходит только в Microsoft и Mojang.

Всё в одном месте

От первых альф до свежих снапшотов, с Fabric, Quilt, Forge и NeoForge.

Игра

  • Все версии, для каждой скачивается нужная Java
  • Fabric, Quilt, Forge (с 1.7.10) и NeoForge ставятся в фоне
  • Автоматическая память и аргументы Java
  • Новая сборка скачивается сразу, поэтому первый запуск быстрый

Моды и модпаки

  • Моды, ресурспаки, шейдеры и датапаки с Modrinth и CurseForge
  • Обновление модпаков без потери ваших дополнений
  • Импорт и экспорт .mrpack и .zip CurseForge
  • OptiFine с официального сайта прямо в лаунчере

Сборки

  • Группы, значки, обложки и ярлыки на рабочем столе
  • Перенос на другую версию игры с заменой модов на подходящие
  • Миры с резервными копиями, серверы в один клик, скриншоты
  • Время в игре для каждой сборки и общее

Аккаунты и скины

  • Вход через Microsoft, несколько аккаунтов сразу
  • Выбор и смена ника прямо в лаунчере
  • Анимированный 3D-просмотр скина, библиотека скинов и плащи

Если что-то сломалось

  • Консоль игры и разбор вылетов с советами
  • Кнопка, которая закрывает зависшую игру
  • «Сообщить о проблеме» само заполняет отчёт об ошибке

Оформление

  • Светлая и тёмная темы, стили Mica и стекло
  • Живые фоны, анимации и звук нажатий по желанию
  • Русский и английский, плюс ещё семь языков машинным переводом
  • Статус в Discord, который можно выключить

Windows

Windows 10 или 11, 64-бит. Установщик сам добавит Microsoft Edge WebView2, если его нет, и сам обновляется. Портативная версия хранит все данные в своей папке.

Установщик Портативный .zip

Linux

64-бит, с WebKitGTK 4.1. Сборки для Linux новые и пока не обновляются сами.

AppImage .deb

Нужен аккаунт Microsoft с купленной Minecraft: Java Edition. Java лаунчер скачает сам. Установщик для Windows пока не подписан, поэтому SmartScreen может предупредить о нём.
